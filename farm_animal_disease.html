4. The AnimalDisease record shape

No schema was loaded for this type — the fields were chosen to hold a working clinical record. Example: urn:ngsi-ld:AnimalDisease:cow025-johnes.

id / typeurn:ngsi-ld:AnimalDisease:cow025-johnes / AnimalDisease
nameSuspected Johne's disease (paratuberculosis) — Bug

statussuspected · anticipated · risk · under-observation
affectedAnimal / affectedGrouprelationship to the Animal(s), or a text scope for herd-level records
atRiskAnimalrelationship array — source dams / at-risk individuals (forecast records)
severitymild · moderate · high (+ "(forecast)" where anticipated)
clinicalSignsarray — observed, or expected if it occurs
suspectedCause / differentialDiagnosisfree text / array of differentials to rule out
diagnosticPlanarray — the tests that would confirm or exclude it
preventiveMeasuresarray — husbandry changes (forecast records)
recommendedTreatmentfree text — drug classes and management, conditional on the diagnosis
treatmentStatuspending diagnosis · monitoring · preventive — not yet occurring
zoonotic / notifiablebooleans, with a zoonoticNote / notifiableNote where relevant
dateDetected / detectedBy2026-09-07 / "FMIS weight-trend review" or "FMIS herd risk review"
locatedAtthe parcel, farm or pen — AgriParcel:003–006, AgriFarm:farm002, Pen:BoarPen

The animal-side hasDisease is the inverse of affectedAnimal — the herd can be queried for open cases from either end.
