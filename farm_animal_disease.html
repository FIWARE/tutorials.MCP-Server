4. The AnimalDisease record shape

There is a schema for this type — the Smart Data Models / FarmData4All (i4Trust) AnimalDisease model, served by the MCP at ontology://agrifood/AnimalDisease. It is deliberately minimal (only id, type, disease are required), so the records use the model's fields where they map and add extension fields for the clinical detail it does not carry. Example: urn:ngsi-ld:AnimalDisease:johnes-001.

Model fields (Smart Data Models AnimalDisease)
disease requiredthe disease as it would be diagnosed — string. e.g. "Johne's disease / paratuberculosis (Mycobacterium avium subsp. paratuberculosis)"
animalsRelationship array → the Animal(s) with or at risk of the disease
datedate-time of diagnosis — set here to the review time 2026-09-07T12:00:00Z (flagging date; nothing is vet-confirmed yet)
diagnosticTestthe test(s) to confirm or exclude it
veterinarianTreatmentRelationship → a VeterinarianTreatment entity. Left unset — that model needs an appliedProduct, and nothing has been administered
veterinarianRelationship → the diagnosing vet. Unset — no vet involved yet
name · locationfrom GSMA-Commons / Location-Commons; name is the human-readable summary
Extension fields (not in the model, added for triage)
statussuspected · anticipated · risk · under-observation
severity · clinicalSignsmild / moderate / high (+ "(forecast)"); signs observed or expected
suspectedCause · differentialDiagnosisworking cause and the list to rule out
preventiveMeasureshusbandry changes (forecast records)
recommendedTreatmentdrug classes and management, conditional on the diagnosis (prose — the eventual VeterinarianTreatment entity supersedes this once something is given)
treatmentStatuspending diagnosis · monitoring · preventive — not yet occurring
zoonotic · notifiablebooleans, with a zoonoticNote / notifiableNote where relevant
detectedBy · affectedGroup · locatedAtwho flagged it; text scope for herd-level records; relationship to the parcel / farm / pen

The animal-side hasDisease is the inverse of animals — the herd can be queried for open cases from either end. Treatments, when actually applied, belong in sibling VeterinarianTreatment entities (ontology://agrifood/VeterinarianTreatment) linked back via veterinarianTreatment.
